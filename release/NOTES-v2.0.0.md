# CFWARP v2.0.0

- Удалён туннельный транспорт HTTP/2: выбор транспорта, fallback, endpoint-
  сканер, конфигурационные поля, CLI-флаги и реализация исключены из backend.
- WARP работает только через MASQUE over QUIC.
- LuCI упрощён: оставлены только необходимые пользователю настройки и короткие
  пояснения; SNI маскировки сохранён.
- Сохранены anti-DPI регистрации, проверка публичного ключа Cloudflare,
  постоянный TUN-reader, очередь в один пакет и автоматический reconnect QUIC.
- Пакет по-прежнему не изменяет маршруты, DNS и firewall.

Пакеты:

- `luci-app-warp` 2.0.0-r1;
- `warp-usque` 4.2.1-r8.
