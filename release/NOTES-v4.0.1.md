# WARP v4.0.1

Легковесный автономный WARP-интерфейс для OpenWrt 25.12 с `apk`.

- Совместимое автоопределение расположения `apk`, `sha256sum`, `ip` и `curl` в
  разных сборках OpenWrt.
- Постоянно устанавливаются только LuCI-приложение, перевод и userspace
  AmneziaWG-бэкенд.
- Регистратор и сканер endpoint загружается во временный каталог только по
  необходимости, проверяется по SHA-256 и не занимает flash после операции.
- Обычное переподключение быстро переиспользует текущий endpoint; поиск другого
  endpoint запускается отдельной кнопкой.
- Фильтры стран и кодов относятся к входным узлам Cloudflare и отделены от
  наблюдаемой страны публичного выхода.
- Поддерживается подключение к WARP endpoint через существующий зарубежный
  туннель. Управляется только точечный маршрут к endpoint; DNS, firewall и
  маршруты пользовательского трафика не меняются.
- В статусе отображаются endpoint, наблюдаемый узел Cloudflare и страна выхода.
- Watchdog восстанавливает текущую сессию без тяжёлого фонового сканирования.
- Поддерживаются `aarch64` и `aarch64_cortex-a53`.

Установка:

```sh
wget -qO- https://raw.githubusercontent.com/BAzeRlok/CFWARP-OPENWRT/main/install.sh | sh
```

После установки выберите интерфейс `warp` в Forkop, PBR или другой системе
маршрутизации. Сам пакет пользовательский трафик на него не направляет.
