# CFWARP v1.7.2

- Уменьшена дополнительная userspace-очередь перед QUIC DATAGRAM с 64 пакетов
  до одного пакета.
- При потерях и множественных параллельных соединениях трафик больше не
  накапливается сразу в двух больших FIFO-очередях; backpressure остаётся в TUN
  с `fq_codel`.
- Сохранён один ожидающий пакет для немедленного переподключения MASQUE без
  возврата старой проблемы со stale TUN readers.

Обновлены пакеты:

- `luci-app-warp` 1.7.2-r1;
- `warp-usque` 4.2.1-r5.
