# WARP

## OpenWrt — 4.2.0-r3

- Обновлён адрес регистрации Cloudflare на `api.devices.cloudflare.com`.
- Добавлен совместимый TLS 1.2 для API с проверкой сертификата, проверка HTTPS
  через временный AWG-туннель и выбор другой точки при сетевой ошибке.
- Компонент регистрации и поиска серверов обновлён до `0.16.0-r5`. Он
  скачивается в `/tmp` только на время операции и не занимает flash постоянно.
- В релизе оставлены только актуальные APK для `aarch64` и `aarch64_cortex-a53`.

Установка или обновление:

```sh
wget -qO- https://raw.githubusercontent.com/BAzeRlok/CFWARP-OPENWRT/main/install.sh | sh
```

Интерфейс выбирается в Forkop, PBR или другой системе маршрутизации.
Существующие VPN, DNS и firewall автоматически не перенастраиваются.
