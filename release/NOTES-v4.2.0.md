# WARP

## OpenWrt — 4.2.0-r3

- Обновлён адрес регистрации Cloudflare на `api.devices.cloudflare.com`.
- Добавлен совместимый TLS 1.2 для API с проверкой сертификата, проверка HTTPS
  через временный AWG-туннель и выбор другой точки при сетевой ошибке.
- Компонент регистрации и поиска серверов обновлён до `0.16.0-r5`. Он
  скачивается в `/tmp` только на время операции и не занимает flash постоянно.
- В релизе оставлены только актуальные APK для `aarch64` и `aarch64_cortex-a53`.

Установка или обновление:

```sh
wget -qO- https://raw.githubusercontent.com/BAzeRlok/CFWARP-OPENWRT/main/install.sh | sh
```

Интерфейс выбирается в Forkop, PBR или другой системе маршрутизации.
Существующие VPN, DNS и firewall автоматически не перенастраиваются.

## Windows — 4.2.0-r4

- Обновлён API регистрации и добавлен режим совместимости TLS 1.2.
- При смене маскировки проверяется новая выборка точек, а не повторяются те же
  четыре адреса. Общее время регистрации ограничено 150 секундами.
- Кнопка «Удалить» полностью удаляет WARP, официальный AmneziaWG и все его
  профили, службы, настройки, ключи и файлы кэша. После выхода удаляется и EXE
  клиента. Перед удалением показывается подтверждение полного состава очистки.
- Компонент регистрации встроен в основной EXE; отдельная загрузка не нужна.
- Сохранены полный туннель IPv4/IPv6 и сторонний DNS UDP/DoT/DoH. Сторонний DNS
  по умолчанию выключен; предзаполнен DoH `dns.zapret.moe/dns-query`.

Скачайте и запустите подходящий файл:

- [Windows x64](https://github.com/BAzeRlok/CFWARP-OPENWRT/releases/download/v4.2.0/warp-windows.exe)
- [Windows ARM64](https://github.com/BAzeRlok/CFWARP-OPENWRT/releases/download/v4.2.0/warp-windows-arm64.exe)

Если Windows требует перезагрузку для окончательного удаления драйвера,
клиент сообщит об этом; автоматической перезагрузки нет.
