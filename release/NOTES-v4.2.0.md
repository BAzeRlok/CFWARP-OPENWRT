# WARP v4.2.0

Автономный WARP-интерфейс для OpenWrt 25.12 и графический full-tunnel клиент
для Windows.

Обновление Windows **4.2.0-r3**:

- Регистрация больше не останавливается на первом AWG-рукопожатии, если через
  эту точку не проходит HTTPS. Добавлены проверка API и ограниченный перебор
  других точек при сетевой ошибке.
- DNS для доступа к API через временный туннель выполняется внутри туннеля.
- Маскировка при регистрации подбирается автоматически. В журнале отображаются
  проверяемые адреса; общий этап ограничен 150 секундами.
- При отказе API, ошибке сертификата или подтверждённом создании профиля
  повторная регистрация не запускается.
- Обновлены только Windows EXE и их контрольные суммы; APK роутера сохранены.

Обновление OpenWrt и Windows **4.2.0-r2**:

- Исправлена первичная регистрация WARP: компонент регистрации теперь получает
  допустимое число потоков и не завершается с ошибкой
  `-sample and -tunnel-jobs must be at least 1`.
- На OpenWrt компонент регистрации и поиска серверов скачивается во временный
  каталог только при необходимости. После операции временные файлы удаляются.
- В Windows этот компонент встроен в основной EXE. Отдельный файл из релиза
  скачивать не требуется; он извлекается в защищённый каталог при установке или
  поиске сервера и проверяется перед запуском.

- Добавлен сторонний DNS: UDP, DoT и DoH, включаемый отдельным переключателем.
- По умолчанию переключатель выключен; в поле указан DoH
  `dns.zapret.moe/dns-query`.
- Кнопка «Применить DNS» сохраняет настройки без поиска endpoint. DoT/DoH
  обслуживает встроенная DNS-служба, работающая и после закрытия окна.
- При ошибке применения восстанавливаются прежние настройки DNS.
- Сетевой AWG backend и перевод OpenWrt сохранены без пересборки.

- Единый Windows EXE теперь открывает нативное графическое окно и не требует
  работы с PowerShell или командной строкой.
- В интерфейсе доступны установка, состояние, подключение, отключение,
  переподключение, поиск лучшего endpoint и полное удаление профиля.
- Параметры поиска endpoint позволяют выбрать число кандидатов, требуемые
  страны и узлы Cloudflare, а также списки исключений.
- Встроенный журнал показывает результат регистрации, сканирования и управления
  службой.
- EXE сам запрашивает UAC, показывает документы Cloudflare, устанавливает
  проверенный официальный AmneziaWG и создаёт full-tunnel для IPv4, IPv6 и DNS.
- Для обычной Windows x64 используется `warp-windows.exe`, для Windows on ARM —
  `warp-windows-arm64.exe`.
- На OpenWrt сохранены контроль задержки, автоматическое сравнение endpoint и
  безопасный откат при неудачном переключении.

OpenWrt:

```sh
wget -qO- https://raw.githubusercontent.com/BAzeRlok/CFWARP-OPENWRT/main/install.sh | sh
```

Windows: скачайте подходящий EXE из списка файлов релиза и запустите его
двойным щелчком.

APK `warp-warpscout` — служебный компонент роутера; установщик скачивает нужную
ревизию автоматически. Предыдущие APK сохранены для совместимости с уже
установленными версиями. Актуальный LuCI-пакет — `luci-app-warp-4.2.0-r2.apk`.
