# CFWARP v2.0.1

- Отдельный интерфейс Cloudflare WARP через MASQUE over QUIC.
- Ускорено восстановление TCP после единичной потери IP-пакета: чистое
  SACK-подтверждение повторяется до порога fast retransmit вместо ожидания
  длительного retransmission timeout.
- Повтор не затрагивает обычные ACK, TCP с данными, UDP и ICMP и включается
  только после уже обнаруженного разрыва TCP-последовательности.
- Сохранены anti-DPI регистрации, проверка публичного ключа Cloudflare,
  постоянный TUN-reader, короткая очередь и автоматический reconnect QUIC.
- Регистрацию и созданный приложением интерфейс можно полностью удалить из
  LuCI; другие сетевые и firewall-настройки не изменяются.

Пакеты:

- `luci-app-warp` 2.0.1-r1;
- `warp-usque` 4.2.1-r9.
