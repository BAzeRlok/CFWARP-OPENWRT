# CFWARP v1.7.4

- HTTP/2 теперь считается подключённым только после проверки реального IP data
  plane: backend отправляет три внутренних ICMP-пробы и требует минимум два
  корректных ответа.
- Если заданный endpoint принимает CONNECT, но не передаёт пакеты или возвращает
  ICMP-отказ, backend параллельно проверяет выборку из пулов
  `162.159.198.0/24` и `162.159.199.0/24` на семи штатных MASQUE-портах.
- Найденный рабочий endpoint используется для текущего соединения и проверяется
  первым при следующем reconnect.
- В HTTP/2 CONNECT возвращён обязательный `capsule-protocol: ?1`; plain CONNECT,
  `cf-connect-proto: cf-connect-ip` и постоянный `TCP_NODELAY` сохранены.
- Добавлены тесты генератора endpoint-пула, ICMP-пробы и классификации
  административного отказа.
- Низкая задержка QUIC и userspace-очередь в один пакет из v1.7.2 сохранены.

Обновлены пакеты:

- `luci-app-warp` 1.7.4-r1;
- `warp-usque` 4.2.1-r7.
