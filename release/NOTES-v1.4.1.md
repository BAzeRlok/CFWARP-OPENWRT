## CFWARP for OpenWrt 25.12.x

Архитектурное обновление автономного релиза:

- добавлен отдельный APK `warp-usque` для package-архитектуры `aarch64`;
- сохранён отдельный вариант пакета для `aarch64_cortex-a53`;
- установщик автоматически выбирает пакет по результату `apk --print-arch`;
- backend в обоих пакетах идентичен и собран для базового ARMv8 (`GOARM64=v8.0`);
- SHA-256 проверяется до установки каждого APK.

Поддерживаемые package-архитектуры: `aarch64` и `aarch64_cortex-a53`.
