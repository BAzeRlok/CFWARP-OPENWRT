# WARP v4.0.2

Легковесный автономный WARP-интерфейс для OpenWrt 25.12 с `apk`.

- Временный помощник специализирован для регистрации WARP и проверки AWG
  endpoint: APK занимает около 3,6 МБ, распакованный бинарник — около 9,2 МБ.
- Сохранены прямая регистрация, безопасный запасной путь регистрации через AWG,
  выбор endpoint реальным трафиком и фильтры стран/узлов Cloudflare.
- Диагностический скрипт регионов использует тот же минимальный помощник и
  формирует компактный текстовый отчёт.
- Помощник проверяется по SHA-256, работает только из `/tmp` и удаляется после
  регистрации или явного поиска endpoint.
- Постоянно устанавливаются LuCI-приложение, перевод и userspace AWG-бэкенд.
- Поддерживаются `aarch64` и `aarch64_cortex-a53`.

Установка:

```sh
wget -qO- https://raw.githubusercontent.com/BAzeRlok/CFWARP-OPENWRT/main/install.sh | sh
```

После установки выберите интерфейс `warp` в Forkop, PBR или другой системе
маршрутизации. Пакет самостоятельно не меняет DNS, firewall и маршруты
пользовательского трафика.
